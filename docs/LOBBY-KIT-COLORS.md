# lobby-kit 配色规范

> 适用于所有使用 lobby-kit 的联机游戏（showhand、海龟汤等），保证风格统一。

## 页面底色

| 用途 | HEX | 说明 |
|------|-----|------|
| 整页底色 | `#F2EBF7` | 香芋浅紫，长时间浏览不累眼 |
| 更淡备选 | `#F7EFF8` | 偏粉调，几乎接近白 |
| 卡片/面板 | `#FFFFFF` | 白色浮在浅紫上做层次 |

## 文字色

| 用途 | HEX |
|------|-----|
| 标题/重点 | `#333333` |
| 正文 | `#444444` |
| 辅助说明 | `#8A8299` |
| 占位符 | `#A29BB5` |

## 边框色

| 用途 | HEX |
|------|-----|
| 输入框/头像默认边框 | `#D8D0E4` |
| hover 边框 | `#B3B3DD` |
| 激活边框 | `#8888CC` |

## 强调色（品牌紫）

| 用途 | HEX |
|------|-----|
| 主按钮/链接 | `bg-brand-600` = `#7676B8` |
| hover | `bg-brand-500` = `#8888CC` |
| 浅色背景块 | `bg-brand-100` = `#E6E6F5` |

## 使用要点

1. **整页 body** 用 `#F2EBF7`，不要用饱和度高于15的粉紫。
2. **白色卡片**直接浮在浅底上，加轻阴影即可，不需要深色遮罩。
3. **输入框**一律白底、浅紫灰边框、文字 #333。禁止深色底+白字。
4. **按钮**：主操作 brand-600 底 + 白字；次要操作白底 + brand-200 边框。
5. **牌背等游戏元素**可以保留深色（扑克牌背本来就是深的），但 UI 组件必须遵守本规范。

## ProfileEditor 组件

lobby-kit 的 ProfileEditor 已按上述规范内置浅色样式：
- 昵称输入框：白底、#D8D0E4 边框、文字 #333
- 头像九宫格：圆形、#D8D0E4 边框、选中时 brand-500 光圈
- 无需额外覆盖 CSS

## 新游戏接入步骤

1. 安装 `@lapismind/lobby-kit`
2. 在全局 CSS 设置 `body { background: #F2EBF7; color: #333333; }`
3. 使用 ProfileEditor 组件，无需额外样式
4. 游戏内 UI 参考上面的色值表
