# 单推卡设计方向（2026-09-20）

> **⚠ 本目录是上一版方案的存档。最终的实现方式与这里写的相反，见下。**

## 结论：顺序反了，已改

这里的方案（`directions.md` 四方向 → 选 A「空的水槽」+ D「表と裏」→ 实施）走的路子是：

1. 卡片自己用 CSS 画水、画浪、画底砂沉木陶罐；
2. 留一个 `.oshi-figure` 槽位，等人物的**透明底立绘**到货；
3. **由版式决定**人物多大、站在哪、头在水线上下。

用户否了这条路，原话：**「图是最高级别优先，图出成什么样我们就怎么做。你应该先看看图怎么生成，
根据结果划定文字范围 水域特效」**。

最终实现正好倒过来：**整张图铺满卡片，文字压在图量出来的安静区里**。
所以本目录里的槽位几何、水线比例、文字列收窄等规格**全部作废**。

## 现在以什么为准

- **实现**：`blog/src/pages/about.astro` 的 `.oshi-card` 一段（CSS 与 markup 里每个百分比都标了出处）。
- **量图**：`blog/scripts/measure-oshi-art.py`（水线／安静区／人物轮廓）、
  `probe-oshi-boxes.py`（候选框能不能压字）、`mock-oshi-card.py`（把真文字画到真图上出样张）。
  **图一换必须重跑这三个**，CSS 里的数才有意义。
- **实机复核**：`docs/agent/scripts/playwright-oshi-card-check.py`（亮/暗 × 七档宽度的几何断言）、
  `playwright-oshi-motion-probe.py`（水区特效在动 + reduced-motion 真停）。
- **作废脚本**：`_legacy/oshi-card-figure-slot/`、`_legacy/oshi-card-mocks/`（含说明）。

## 仍然成立、已被实现吸收的部分

- **A+D 的核心判断**：签名句「谢谢你，找到了我。」不做常驻标语，是"被放进来"的报酬。
  现在的做法是它沉在水里、只有一句，比原来常驻在水区更像"捞上来的一句话"。
- **构图简报**：`右侧角色构图与出图规格.md` 里那份「蜷缩在缸里、上身在右、下肢在底、
  头贴水面、朝左看；夜里头往水里沉」的规格，是最终两张图的实际来源。改动只在于
  **改由出图直接带上水族箱背景**（用户：「干脆让GPT连着背景一起重新出图算了」），
  于是抠图、调色、自绘水景全都不需要了。
- **两条颜色结论**（做过实验、仍然有效，只是最终没用上）：
  作画与水色打架的根因是**饱和度**不是色相（`saturate()` 能救）；本卡的青色区在 202–212°。
