# Planning Workspace

本目录存放仍在进行中的任务计划和调查记录，避免 `task_plan.md`、`findings.md`、`progress.md` 散落在仓库根目录。

## 规则

- 每个独立任务使用一个子目录：`YYYY-MM-DD-task-name/`。
- 子目录内可以包含 `task_plan.md`、`findings.md`、`progress.md`。
- 计划文件记录进行中的工作，不替代 Git 提交和项目交接日志。
- 任务完成后，将需要长期保留的上下文整理到对应项目的 `docs/session-logs/`；计划目录可保留作调查证据，也可在确认无用后删除。
- 不在计划文件中记录密钥、Cookie、Token 等敏感信息。
