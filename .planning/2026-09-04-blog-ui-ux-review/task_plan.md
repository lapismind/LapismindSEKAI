# 博客 UI/UX 评测计划

## 目标
对博客网站进行一轮有证据的美术、UI 与用户体验评测，覆盖源码与线上桌面/移动端，不直接修改现有博客。

## 阶段
- [complete] 1. 梳理博客技术栈、页面结构与设计意图
- [complete] 2. 建立适合该博客的设计评测基线
- [complete] 3. 在线检查桌面端、移动端、交互与可访问性
- [complete] 4. 汇总问题、优先级与优化建议，形成 v2 评测报告
- [complete] 5. 自检证据、局限和已知教训后交付
- [complete] 6. 实施用户确认的低风险 UI/UX 优化
- [complete] 7. 本地回归、独立代码审阅与问题修复
- [complete] 8. 部署生产环境并完成生产回归
- [complete] 9. 审查并提交本轮改动

## 错误记录
| 错误 | 尝试 | 处理 |
|---|---:|---|
| 误调用空 `apply_patch`，工具中止 | 1 | 未产生文件改动；后续只提交含实际 diff 的补丁。 |
| 当前模型无法读取浏览器截图内容 | 1 | 截图保留供用户人工对照；评测结论改用 DOM 几何、交互状态、焦点与资源数据，不编造视觉观察。 |
| PowerShell 内联 Python/JavaScript 的引号解析失败 | 1 | 不重试复杂单行命令；把 320px 视口加入现有 Playwright 审计脚本。 |
| 实施阶段再次误调用空 `apply_patch` | 2 | 未产生改动；停止预调用工具，先准备完整 diff。 |
| 新增测试的补丁上下文顺序错误 | 1 | 补丁整体未应用；读取当前文件后按真实上下文重做。 |
| 多文件补丁中 `index.astro` 片段顺序不匹配 | 1 | 补丁整体未应用；改为按文件小批次修改和验证。 |
| PowerShell 在 `&&` 后解析 `$env:BLOG_BASE_URL=...` 失败 | 1 | 命令未执行；停止、启动预览和带环境变量测试拆成独立调用。 |
| 工具流在响应完成前断开 | 1 | 属工具连接错误，无代码或部署副作用；依据工作区和后续命令实际结果继续。 |
| `npm audit` 请求 npmmirror 返回 404 NOT_IMPLEMENTED | 1 | 镜像不提供审计 API，不代表无漏洞；改用 `--registry https://registry.npmjs.org` 重跑。 |
| 官方 npm registry 审计 180 秒无输出超时 | 2 | 无漏洞结论不可得；本轮无依赖变更，记录为发布检查局限，不再盲目重试。 |
| MusicDock 44px 热区回归测得 42.76px | 1 | 测试点击后立即读取，命中父面板 `scale(0.97)` 过渡中间帧；等待 `transform: none` 后再测稳定尺寸。 |
| 修复审阅问题的多文件补丁上下文不匹配 | 2 | 两次整体未应用；读取真实 CSS 与计划表后拆成小补丁。 |
| 焦点与目录首轮修复后回归仍失败 | 1 | 焦点被后加载的等特异性页面规则覆盖；动态 TOC 链接缺 scoped 属性。删除局部 `outline:none`，目录链接改用 `:global`。 |
| 生产回归 3 项在 `networkidle` 超时 | 1 | 关键 URL 均 200，持续媒体请求使网络静默不可靠；改为 `domcontentloaded` + 元素就绪等待后重跑。 |
| 改用 DOM 就绪后出现 strict selector 与目录状态竞态 | 1 | 就绪 locator 改为 `.first`；目录点击后显式等待 `.open` 和链接可见。 |
| 生产目录开关早于 `astro:page-load` 初始化 | 1 | 点击前等待动态目录链接生成，再验证展开状态。 |
| 暂存 diff 有 3 处 Markdown 行尾空格 | 1 | `git diff --cached --check` 报错；清理后重新暂存和检查。 |
| 敏感信息扫描命令找不到 `rg` | 1 | 命令未执行；改用专用 Grep 工具检查本轮文件。 |
| 最终生产 skip-link 回归一次无信息失败 | 1 | 其余 5 项通过；为断言补路径与失败阶段后重跑定位，不据空错误下结论。 |
