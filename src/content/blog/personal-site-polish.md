## 先说 bug

朋友跟我说：从主页点进 projects，屏幕上糊着一层图，游戏页根本看不见。

我打开一看还真是。全屏入场动画本该播完就消失，结果跟着页面切换跑到了 projects 页上，赖着不走。

原因是这样：Astro 的 View Transitions 切页时会保留旧页面 DOM 再替换，挂在 body 上的动画层就趁这个空档被带到了新页面。而清理脚本的逻辑是"sessionStorage 标记播过就直接 return"——它只管不重播，不管删东西。动画层到了新页面上没有任何人处理，就永远停在那里。

这事要凑齐三个条件才会发生：动画层只在主页渲染、换页携带旧 DOM、脚本看到标记就提前退出。前几轮修各补了一个洞，这次总算补齐了：

```js
function cleanupStaleIntro() {
	const el = document.getElementById('intro');
	if (!el) return;
	const isHome = window.location.pathname.replace(/\/+$/, '') === '';
	if (!isHome || window.__introDone) {
		el.remove();
	}
}
document.addEventListener('astro:before-swap', cleanupStaleIntro);
window.addEventListener('astro:after-swap', cleanupStaleIntro);
```

换页前后各挂一道清理，不在主页或者播过就删。另外把脚本里所有"不该播"的情况收拢到一个分支，跳过播放的同时顺手删元素。之后再怎么切页面，都不会留孤儿节点。

## 借这个机会聊聊美化

站是一点点调出来的，没用模板。要说什么方法，就一句：先定气质，再挑东西。

我给站定了三个词：夜色、二次元、玩家档案。

配色整站走深蓝紫，oklch 调的，暗但不闷。首页背景用了一张《世界计划》的卡面，页脚注明素材来自 pjsk.moe、版权归 SEGA 和 Colorful Palette。头像旁边挂个绿点，写"LV.1 成长中"；首页文案照角色卡的思路写，"谢谢你，找到了我"，配真冬那句「見つけてくれて、ありがとう」。

这三个词同时也是筛子。后来每次想加新东西，先过一遍，不搭就不做。毛玻璃卡片、粒子背景这些流行元素我试过一些，最后留下的没几个，大部分因为气质不合被砍了。

## 入场动画这东西

三块斜切面板，各压一张卡面，缓慢放大，两秒后依次向上掀开。技术上不难，clip-path 加 keyframes 就够，麻烦全在细节。

我给自己立了三条规矩。一个会话只播一次，sessionStorage 记标记，回头客直接进正题。系统开了"减少动态效果"的用户不播，动画再好看也不该硬塞给别人。还有一条就是这次栽的坑：无论哪条路径退出，动画层都必须被删掉，兜底逻辑不能假设任何前提。

仪式感是给第一次来的访客的，第二次来的人只想看内容。

## 一些小东西

Live2D 看板娘蹲在右下角，YUKI，能切换模型，头顶挂着站点运行天数。二次元网站没有看板娘总觉得缺了点什么。

音乐播放器做成悬浮电台，内置几首箱曲，歌词中日双语滚动，音源可以在 Virtual Singer 和 SEKAI 版本之间切。入口藏在首页那张"今日箱曲：バグ"按钮后面，平时不占地方。

雪花是 canvas 画的，密度压得很低，只在深色主题下开。控制台里藏了一段 ASCII 字符画和一句暗号，输入 `lapismindSignal()` 可以再呼出来——成本几乎为零，但真会有人打开开发者工具。

这些东西的共同点：都贴着"玩家档案"这个人设长出来，而且都不挡正文。

## 页面不能变卡

美化最怕把性能搭进去。几个实际管用的做法：

图片全部交给 Astro 构建期转 webp，一张 1900px 宽的卡面压完几十 KB。字体自托管，霞鹜文楷做了子集化，按需加载，不用整套下载。动画只用 transform 和 opacity，这两个属性走合成层，不引起重排。雪花和粒子共用一个 canvas，帧率交给 requestAnimationFrame 管。

页面变卡了就先查图片格式和动画属性，大部分问题出在这两处。
