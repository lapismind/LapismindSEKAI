部署就三条命令：

1. 安装 Wrangler
npm install -g wrangler
2. 登录
wrangler login
浏览器弹出授权页面，点同意。

3. 部署
cd 你的项目目录
wrangler deploy
前提：项目里要有 wrangler.toml
让 OpenCode 在项目根目录生成这个文件：

name = "card-game"
main = "index.js"
compatibility_date = "2024-09-23"

[[durable_objects.bindings]]
name = "GAME_ROOM"
class_name = "GameRoom"

[[migrations]]
tag = "v1"
new_classes = ["GameRoom"]
name — Worker 名称，随便取
main — 入口文件路径
class_name — 你的 Durable Object 类名，要和代码里 export class 的名字一致
migrations — 首次部署必须加，告诉 Cloudflare 注册这个 DO 类
本地调试（可选）
wrangler dev
打开 http://localhost:8787 看效果。

注意事项
如果之后改了 Durable Object 的类名或新增了 DO 类，需要在 migrations 里加新的 tag（比如 v2）
部署成功后终端会输出 https://card-game.你的子域名.workers.dev，打开就能用
WebSocket 在 wrangler dev 本地也能跑，可以多开几个浏览器标签测试多人
