# 新游戏立项选型 Plan

> 用户目标：做一款多人联机网页游戏。
> 状态：brainstorming 阶段——方向已从「出包魔法师」转向**梭哈（Stud Poker）**。

## 已确认决策（可推翻，需用户拍板）

| 决策 | 内容 |
|------|------|
| 方向 | **梭哈（Stud Poker）**，弃桌游换皮路线 |
| 玩法 | 五张梭哈（Five-Card Stud）+ 七张梭哈（Seven-Card Stud）双玩法 |
| 赛制 | 多轮对局后**积分最高者胜出**（非真钱，虚拟积分） |
| 形态 | 数字版网页游戏，多人联机 |
| 技术栈 | Vue3 + Vite + Tailwind + Cloudflare Workers + Durable Objects + WebSocket（复用海龟汤架构） |

## 本次任务
