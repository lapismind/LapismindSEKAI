## 1. UI 风格统一性（优，一处破绽）

**做得好的**
- 全站色彩由 --hue-accent: 283（真冬紫 #8888CC）一个变量经 OKLCH 推导，亮/暗两套完整主题（src/styles/global.css）。
- Header / Footer / BaseHead 全站复用，导航、页头阴影、回到顶部、细雪 canvas 行为统一（BaseHead.astro 里集中管理）。
- 字体（霞鹜文楷屏显 + Atkinson）、自定义鼠标、玻璃卡片、圆角/阴影体系各页面一致。
- 首页/关于/作品集/博客/404 五类页面全部吃同一套变量，手写样式风格统一。

**破绽**
- src/components/CommentSection.vue 是全站唯一用 Tailwind 库存色的组件：purple-600、slate-* 硬编码，与主色 #8888CC 不同色相；且没有玻璃卡片、自定义光标、等宽 eyebrow 这些站内元素。与旁边的 UserAvatar.vue（走 CSS 变量）形成双风格。

## 2. 用户认证链路（中上，五条缺口）

链路盘点（auth/ 服务 + lobby-kit auth 客户端）：

GitHub OAuth（state 防 CSRF + redirect 域白名单）→ 游客会话 → 账号注册/密码登录（PBKDF2-SHA256，100k 迭代）→ HttpOnly+Secure+SameSite=Lax 会话 cookie（Domain=.qmzhj.top 多子域共享，30 天）→ 评论鉴权（github/account 可发，游客只读，管理员可删）→ 自选头像 → 战绩上报与成就。

这条主链路验证过：匿名 401、登录后可发、第 6 条 429、超长 400、游客→注册保留 playerId 均有测试覆盖；生产域 auth.qmzhj.top 可达（/api/me 正常返回）。

**缺口**
1. 密码无找回/修改：账号不绑邮箱，忘密码即永久丢失（schema.sql 无 email 字段）。对"认证链路完整"而言是最大缺口。
2. 密码登录无限频：handlePasswordLogin（auth/src/index.js:303）无任何限流/锁定，可离线慢速撞库；注册限频是全局 3 次/分钟（合法用户可能被误伤），而不是按用户名/IP。
3. 评论列表不回传 avatar_id：listComments 只 SELECT u.avatar_url（auth/src/index.js:520），账号用户自选头像不会出现在评论区——头像是"选了自己看不到"的半成品。
4. 资料页 GitHub 主页链接拼错：用数字 githubId 拼 URL（blog/src/pages/profile.astro:456），实测得到 https://github.com/12345678（死链）；应使用 GitHub 登录名 nickname。
5. 评论无超时/重试 + 硬编码 authBaseUrl：评论区加载没有超时兜底（auth 慢时一直"加载中…"，资料页有重试它没有）；authBaseUrl prop 默认值硬编码生产域（CommentSection.vue:10），本地起 auth 也无法联调评论。

## 3. 交互体验（中，五个实锤问题）

Playwright 实测（本地 preview + 模拟 GitHub 身份 + SPA 切页）：

1. 播放器在 SPA 切页后交互失效：bind() 里的 if (window.__mdBound) return（MusicDock.astro:222）让第二次及以后切页时不再挂事件，但 els 已指向新 DOM——听众还在旧（已移除）元素上。实测：首页→博客→回首页后，打开/播放按钮点击无任何效果（aria-expanded 不变、面板不开）。
2. 切页即重置播放（"切页不断歌"名不副实）：每次 astro:page-load 都执行 init() → setTrack(defIdx) + 重设 audio.src（MusicDock.astro:307），实测切页后 playing 状态被清、回到默认曲。site-features.md 声称的"切页不断歌"与实现不符。
3. 播放中标题仍显示"（未播放）"：init() 在 setTrack 后又强制加后缀（MusicDock.astro:309），播放按钮不更新标题。实测 playing=true 时标题仍是"バグ（未播放）"。
4. 中文歌词字幕实际不可用：/music/lyrics/music_*.json 目录只有 README，六首歌全部 404（实测网络面板确认）。前端有完美降级（只显示日文 LRC），所以不崩但"中文对译字幕"这个卖点没有数据支撑。
5. 评论分页没有第 2 页入口：后端支持 page/page_size（auth/src/index.js:527），前端 page 状态永远停在 1，没有"加载更多/翻页"控件，评论超过 20 条后无法查看。

**加分项**：主题切换 + localStorage 记忆无闪烁；prefers-reduced-motion 全站降级；入场动画孤儿清理的 before/after-swap 双保险（这处修得漂亮）；404 页有返回入口；评论区有 500 字计数与 429/401 分级提示。

**验证通过**
