# Showhand（梭哈）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现多人联机梭哈网页游戏，支持五张/七张梭哈、完整下注、固定局数积分赛、观众席。

**Architecture:** 前端 Vue3 + Vite + Tailwind（复用海龟汤大厅通用件），后端 Cloudflare Workers + Durable Objects（服务端权威发牌），WebSocket 实时通信，SQLite 持久化。房间状态由单个 DO 实例（ShowhandRoom）管理。

**Tech Stack:** Vue3, Vite, Tailwind, Pinia, Cloudflare Workers, Durable Objects, WebSocket, wrangler

## Global Constraints

- 协议消息格式：与海龟汤一致的 `{ type, data }` 信封，`makeMessage`/`isServerMessageValid` 在 `src/core/protocol.js`
- 服务端权威：所有发牌/下注校验在 DO 内，客户端零信任
- 防作弊：客户端只收到自己的暗牌；观众视角由服务端标记
- 文件编码 UTF-8（P02 规则：不用 PowerShell Set-Content 批量改文件）
- 每任务结束跑 `npm run build` 验证（P04 规则）
- 中文 UI，工程模式代码（无 AI 腔文案）

export { ShowhandRoom }

export default {
  async fetch(request, env) {
    const url = new URL(request.url)

    if (url.pathname.startsWith('/ws')) {
      const roomId = url.searchParams.get('roomId')
      if (!roomId) return new Response('missing roomId', { status: 400 })
      const id = env.ROOM.idFromName(roomId)
      const stub = env.ROOM.get(id)
      return stub.fetch(request)
    }

    return env.ASSETS.fetch(request)
  },
}
```

  RCV_BET_RESULT: 'bet_result',
  RCV_SHOWDOWN: 'showdown',
  RCV_GAME_OVER: 'game_over',
  RCV_PLAYER_JOINED: 'player_joined',
  RCV_PLAYER_LEFT: 'player_left',
  RCV_SPECTATE_STATE: 'spectate_state',
  RCV_ERROR: 'error',
}

export function makeMessage(type, data = {}) {
  return { type, data }
}

export function isServerMessageValid(raw) {
  if (!raw || typeof raw !== 'object') return false
  if (typeof raw.type !== 'string') return false
  return raw.data === undefined || (typeof raw.data === 'object' && raw.data !== null)
}
```
