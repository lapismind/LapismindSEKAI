Live2D 模型可用性说明

每个角色都有完整的 Live2D 模型（moc3 + 贴图 + 物理），以及 200–370 个动作/表情文件。
但动作 JSON 只有元数据（FadeInTime/FadeOutTime），实际动画曲线内嵌在 Unity clip 里，网页端无法直接播放。
如果要用 Live2D，需要引入 pixi-live2d-display 库并自己写 idle 呼吸动画（不加载外部 motion 文件）。
模型体积：moc3 约 1MB + 贴图约 2MB = 每个角色约 3MB。
