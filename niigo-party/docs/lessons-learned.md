## 已解决

### 2026-09-29 · 生成式重绘后的底图，不能靠 2D 偏移去贴格子

- **现象**：Image 2.5 重绘棋盘后，白色底座与 Blender 导出坐标偏差中位 ~14px（格宽 ~110px），
  且每格方向各异。给 2D 色块加逐格偏移，幅度一改就"有的到位、有的反而歪了"。
- **根因**：生成式模型是整图重画，格子几何被逐格扰动，不存在统一的仿射变换。
- **解法**：格子不交给生成模型。重绘时用遮罩保护格子区域；格子层始终由 Blender 同相机渲染后叠回。
  过渡期底图地砖不上色，用格子上方小徽章标类型（棋子有体积，站偏十几像素看不出，满铺色块偏了很扎眼）。
- **测量方法本身有系统误差**：在 Blender 原图（理应零偏差）上跑同一测量也报 ~16px。
  评估偏差要"重绘图读数 − 原图读数"，不能直接信测量绝对值。

### 2026-09-29 · chibi 基底是 1024² 白底 RGB，没有 alpha

- **现象**：棋子直接贴 chibi 图是白方块；按 512² 假设裁头像，裁出来是全身。
- **解法**：头像用圆形 clipPath 裁；裁剪框按实际 1024² 计算（头部约 x 290–710、y 50–470）。
  嵌套 `<svg viewBox>` + `clipPathUnits="objectBoundingBox"` 在 Chromium 里没按预期裁，
  改用"缩放 `<image>` + `userSpaceOnUse` 圆形 clipPath"。

### 2026-09-30 · 改了移动规则，射程判定没跟着改

- **现象**：站在十字路口旁放「爆破专家」，四条路里只有两条能放。
- **根因**：交点改成三向路口时，移动改走无向邻接加朝向，射程还用旧的 `directedDistance`，只沿环的正向搜，
  所以身后和路口左转那条路都够不着。进度里还写过"射程未改"，当时没追问这样对不对。
- **解法**：射程改用无向最短步数 `tileDistance`（按 `neighbors` 做 BFS）。
  以后改移动或拓扑规则，要把所有依赖拓扑的判定（射程、距离、AI 选格）一起过一遍。

### 2026-09-30 · 每回合限 1 张牌只挡了一种卡牌类型

- **现象**：反制牌（保护屏障 / 以牙还牙）不受"每回合 1 张"限制，一回合能连出反制 + 效果牌。
- **根因**：卡牌按 `kind` 拆成 battle / effect / counter 后，限张判定写在 `card.kind === 'effect'`
  分支里；拆类型时这条横切约束没跟着搬。battle 牌走同一入口还会被静默消耗（毫无效果）。
- **解法**：限张挂在"掷骰前出牌"这个动作上——`playEffectCard` 对所有 kind 统一判 `effectPlayed`
  并置位；battle 牌直接 guard（只能走战斗选牌消耗）。
- **教训**：跨类型的横切约束（每回合限 X、上限 Y）要挂在动作 / 阶段上，不要挂进某个类型分支。
