## 玩法骨架

```
图版层（复刻星引擎）
  棋盘 + 地块效果 + 战斗系统 + 卡牌系统
  胜利条件：星币 → 升级格 → 等级
        ↓
小游戏层（借鉴揍击派对，星引擎没有这层）
  每 N 回合一场，全员同时参与
        ↓
结果展示 ← 动画的高价值落点
```

**角色**：`mfy` / `ena` / `kanade` / `mizuki`，各带主动 + 被动技能。
