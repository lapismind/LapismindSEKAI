## 已定的决策

| # | 决策 | 依据 |
|---|---|---|
| 1 | **四人局**（2~4 真人，人机补位） | 小游戏层需要全员同时参与，2 人会让派对节奏变形 |
| 2 | **全程回合制** | 实测延迟中位 362ms、最差 4.8s（实时对战不可行）。根因是免费版把流量路由到欧洲 |
| 3 | **题材 = 25時四人** | mfy / ena / kanade / mizuki，同一组合，天然填满 4 个位置 |
| 4 | **玩法 = 图版层复刻星引擎 + 小游戏层借鉴揍击派对** | 星引擎只有地块效果，**没有小游戏层**；那层是我们要加的差异化 |
| 5 | **美术 = 素材在另一个仓库** | 见 `../AGENTS.md` 的跨仓库约定 |

## 玩法骨架

```
图版层（复刻星引擎）
  棋盘 + 地块效果 + 战斗系统 + 卡牌系统
  胜利条件：星币 → 升级格 → 等级
        ↓
小游戏层（借鉴揍击派对，星引擎没有这层）
  每 N 回合一场，全员同时参与
        ↓
结果展示 ← 动画的高价值落点
```

**角色**：`mfy` / `ena` / `kanade` / `mizuki`，各带主动 + 被动技能。
